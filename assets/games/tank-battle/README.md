# Tank Battle

A classic tank battle game built with pure HTML5 Canvas and JavaScript. No dependencies required.

## How to Play

Open `index.html` in any modern browser to start playing.

### Controls
- **WASD / Arrow Keys** — Move your tank
- **Space** — Shoot
- **P** — Pause/Resume
- **R** — Restart

### Gameplay
- Destroy all enemy tanks to advance to the next level
- Enemies spawn continuously and will chase and shoot at you
- Collect power-ups to heal, gain speed boosts, or rapid fire
- Breakable walls can be destroyed by bullets
- You have 3 HP — lose all HP and it's game over

### Features
- 3 unique level layouts (cycles with increasing difficulty)
- Enemy AI with pathfinding and shooting
- Destructible terrain
- Power-up system (Heal, Speed Boost, Rapid Fire)
- Explosion effects
- Score tracking
- Pause and restart support

## Tech Stack

- HTML5 Canvas
- Vanilla JavaScript
- No external dependencies
