# 本地小游戏

`2048.html` 与 `tetris.html` 是志林网站中的独立本地试玩页面，代码位于本目录的 `games.js`、`games.css` 与 `theme.js`。键盘、方向控制、触屏控件及游戏循环由本站代码实现；没有复制上游仓库的源码、图像、品牌或页面。

- 2048 的玩法设计参考：[Gabriele Cirulli / 2048，固定提交 `478b6ec346e3787f589e4af751378d06ded4cbbc`](https://github.com/gabrielecirulli/2048/tree/478b6ec346e3787f589e4af751378d06ded4cbbc)，上游仓库提供 MIT License：[LICENSE.txt](https://github.com/gabrielecirulli/2048/blob/478b6ec346e3787f589e4af751378d06ded4cbbc/LICENSE.txt)。
- 方块玩法参考：[Dionysis Zindros / canvas-tetris，固定提交 `4e497d1c858914f0a1f0818698029d1c7dad090b`](https://github.com/dionyziz/canvas-tetris/tree/4e497d1c858914f0a1f0818698029d1c7dad090b)，上游仓库提供 MIT License：[LICENSE.md](https://github.com/dionyziz/canvas-tetris/blob/4e497d1c858914f0a1f0818698029d1c7dad090b/LICENSE.md)。

这些许可证链接仅用于说明被参考的上游仓库；不表示本站试玩代码是其源码的副本、移植或派生发行。
