# 内容后台上线接入

这些文件是已完成本地校验和独立代码审核的接入包，尚未上传到服务器或写入生产仓库。真实账号和服务器结果仍须按下方步骤验收。

## 1. 首次源码接入

目标源仓库：`/Users/apple/Desktop/jianli/personal-site`，远端 `zhilinYu/zhilin-personal-site`。保留现有 `payment/`、`deploy/zhilin-shop.service`、`assets/checkout.js`、测试与简历改动。

同步新版首页、`assets/`、`admin/`、`content/`、`templates/`、`tools/`、本次新增的四个测试和 `tests/fixtures/migration.json`、`package.json`、锁文件及后台说明；不要覆盖原支付测试目录。原支付测试命令继续保留在原发布流程中。

将 `content-deploy.yml` 放到 `.github/workflows/content-deploy.yml`；将 `legacy-deploy.yml` 的触发条件、Node 安装、静态构建及上传步骤接入原 `.github/workflows/deploy.yml`。后者保留原支付步骤，只有 `payment/`、`deploy/zhilin-shop.service`、`assets/checkout.js` 或原支付前台测试变更才自动触发；也保留手动发布入口。首次后台接入、文章及资源更新不会重启支付。两个流程都从当前 JSON 生成发布包，避免下次支付部署用旧首页覆盖新内容。混合提交共用 `zhilin-production` 串行锁。

接入前实时检查仓库可见性。公开仓库的草稿分支不保密；需要保密的草稿使用私有仓库。当前文件只包含公开内容，不包含收费全文。

## 2. GitHub OAuth App

由账号持有人在 GitHub Developer settings 创建 OAuth App：

| 字段 | 值 |
| --- | --- |
| Application name | 志林网站内容后台 |
| Homepage URL | https://zhilin.club |
| Authorization callback URL | https://zhilin.club/cms/callback |

Client ID 和 Client Secret 只填写到服务器 `/etc/zhilin-cms/cms.env`。按 `cms.env.example` 的字段配置，文件权限为专用服务账号可读的 `0640`；不要发进聊天或保存到仓库。

## 3. 授权服务

确认服务器有 Node.js 22 或更新版本，创建专用 `zhilin-cms` 服务账号。将 `deployment/oauth.mjs` 放到 `/opt/zhilin-cms/deployment/oauth.mjs`。该服务只用 Node 标准库，不需要另装 npm 包。

根据服务器实际 Node 路径设置 `zhilin-cms-auth.service` 的 `ExecStart`，再安装服务单元。它监听 `127.0.0.1:9102`，与支付服务的 9101 分开；先确认 9102 未占用。

把 `cms.nginx.conf` 的 location 加入现有 HTTPS server。只新增授权和后台路径，保留原支付代理。先验证 Nginx 配置再 reload；启动授权服务后检查 `/cms/health`。

## 4. 备份与首次发布

先通过现有 `deploy/preflight_backup.py` 备份核验门禁，确认 `verified=true` 后再发布。内容工作流也保留这个门禁，不创建新的订单／私有商品备份方式。

`node tools/export.mjs` 生成 `deployment/site/`，只包含页面、后台、公开静态资源及简历。CMS 内容源、模板、依赖和私有配置不上传为网页文件；线上后台直接使用 GitHub API 保存内容。

授权服务首次安装独立进行，日常内容发布流程不会重启支付或授权服务。发布内容时需要检查 Actions 的结果；失败时按备份门禁记录恢复静态代码，不覆盖订单库。

## 5. 必须完成的线上验收

1. 指定 GitHub 账号能登录，其他账号被拒绝；token 和回调参数不进入日志。
2. 在专用测试分支验证草稿保存、重新编辑与发布合并，未发布内容不进入正式页面。
3. 创建、更新、隐藏文章与提示词；上传公开 ZIP，校验下载文件一致。
4. 纯内容发布只更新静态目录，支付服务不重启；线上现有支付状态与购买入口按原验收标准独立检查。
5. 在桌面和手机确认六栏目、蓝猫动效、正文、复制与下载。
